Grabbit 1.3.0
- New download engine: large files download on up to 6 parallel connections and HLS streams fetch 4 segments at a time.
- Every connection retries and resumes from where it stopped, so a network blip no longer restarts the download.
- Live speed, ETA, percentage and size in the notification and the Downloads list.
- Refuses to save login walls or error pages as "videos"; warns when a file is already downloading.
